# THIQA UNI | Your Global Education Partner — ثقة يوني للتعليم الدولي

منصة وبوابة رقمية رسمية لـ **THIQA UNI (ثقة يوني)** للاستشارات والخدمات الأكاديمية الدولية، المخصصة لتوجيه وقبول الطلاب الدوليين في أفضل الجامعات المعترف بها في ماليزيا وآسيا.

---

## ✨ المميزات الرئيسية (Key Highlights)

- **الهوية البصرية الرسمية (THIQA UNI Brand)**: متطابقة بالكامل مع شعار THIQA UNI الرسمي، ونظام ألوان أكاديمي دولي (Navy `#0F254B` و Gold `#F59E0B`).
- **مسار الطالب الاستراتيجي (Discover → Compare → Choose → Apply)**: خريطة طريق منظمة تضمن للطلاب وأولياء الأمور رحلة واضحة من الاستكشاف والمقارنة وحتى استلام القبول والتأشيرة (VAL).
- **مستشار التخصص والجامعة الذكي (Pathway Advisor Modal)**: أداة تفاعلية سريعة لاقتراح المسارات المناسبة للطالب بناءً على مستواه الأكاديمي، تخصصه المطلوب، وميزانيته السنوية.
- **دليل الجامعات الشريكة (Universities Explorer)**: تصفية وبحث فوري للجامعات الحكومية، والخاصة، وفروع الجامعات العالمية مع تفاصيل الرسوم ومواعيد القبول (Intakes).
- **دليل التخصصات المستقبلية (Future Programs)**: استعراض شامل لتخصصات الذكاء الاصطناعي، الأمن السيبراني، الهندسة، إدارة الأعمال، علوم البيانات، والعلوم الصحية وطب الأسنان.
- **نموذج التقاط المهتمين عالي التحويل (Lead Capture Modal)**: نموذج جمع بيانات متوافق مع معايير التسجيل الأكاديمي مع متابعة فورية عبر واتساب.
- **زر واتساب العائم (WhatsApp Floating Button)**: مثبت بالزاوية المناسبة للتواصل السريع مع المستشار الأكاديمي.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4 + Swiss Modernism 2.0 Design System
- **Icons**: Lucide React
- **Animations & Effects**: Framer Motion + Canvas Confetti
- **Linting & Quality**: Oxlint + TypeScript strict mode

---

## 🚀 تشغيل المشروع محلياً (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build

# فحص الكود والجودة
npm run lint
```
