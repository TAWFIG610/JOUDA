# ثقة يوني | THIQA UNI

موقع شركة ثقة يوني لاستشارات القبول الجامعي في ماليزيا، بالعربية والإنجليزية. يعرّف بالشركة وخدماتها والجامعات، ويتضمن أداة لاختيار التخصص ونموذج استشارة يُرسل عبر واتساب.

## التقنيات

- React 19 و TypeScript
- Vite
- Tailwind CSS v4
- Lucide React للأيقونات
- Oxlint لفحص جودة الكود

## البدء محلياً

يتطلب المشروع Node.js و npm.

```bash
npm install
npm run dev
```

## أوامر المشروع

```bash
npm run build   # فحص TypeScript وإنشاء نسخة الإنتاج
npm run lint    # فحص الكود باستخدام Oxlint
npm run preview # معاينة نسخة الإنتاج محلياً بعد البناء
```

## هيكل المشروع

- `src/App.tsx` ترتيب أقسام الصفحة: من نحن ← خدماتنا ← خطوات التقديم ← الجامعات ← الدراسة في ماليزيا ← أسئلة قبل التقديم ← تجارب الطلاب ← الأسئلة الشائعة ← التواصل.
- `src/components/` أقسام الصفحة (`*Section.tsx`) والنوافذ المنبثقة (`*Modal.tsx`).
- `src/components/ui/` مكونات مشتركة (الحركة عند التمرير، رأس القسم، النافذة المنبثقة).
- `src/data/thiqaData.ts` محتوى الموقع: الجامعات، بيانات الشركة (`COMPANY`)، الخطوات، الأسئلة، التجارب.
- `src/i18n/` تبديل اللغة واتجاه الصفحة.
- `src/lib/` التتبع (`analytics.ts`) وحفظ الطلبات (`leads.ts`).
- `src/hooks/` خطافات التمرير والظهور في الشاشة.
- `src/index.css` ألوان الهوية والخطوط ومقاسات التخطيط والنصوص والأزرار (Tailwind `@theme`).
- `src/types/` تعريفات TypeScript المشتركة.
- `public/` الشعار وأصول الجامعات وصورة المشاركة والملفات العامة.
- `docs/` أدلة الإعداد.

## بيانات الشركة

املأ `COMPANY` في `src/data/thiqaData.ts` (رقم السجل التجاري، العنوان، ساعات العمل، البريد). كل حقل فارغ يبقى مخفياً، وتظهر القيم تلقائياً في قسم «من نحن» وفي التذييل.

## الإعدادات الاختيارية

انسخ `.env.example` إلى `.env.local` (أو أضف القيم في لوحة الاستضافة). كل إعداد يبقى معطّلاً إذا تُرك فارغاً:

- `VITE_GA_ID` — معرّف Google Analytics 4 لتتبع الزيارات والضغطات (فتح النموذج، الإرسال، واتساب، تغيير اللغة).
- `VITE_PLAUSIBLE_DOMAIN` — بديل Plausible لنفس التتبع.
- `VITE_LEADS_ENDPOINT` — حفظ نسخة من كل طلب في Google Sheets. خطوات الإعداد في `docs/google-sheet-leads.md`.

## اللغات

الموقع بالعربية افتراضياً، والنسخة الإنجليزية عبر زر اللغة أو الرابط `?lang=en`. النصوص في `src/data/thiqaData.ts` وفي كائن `TEXT` داخل كل مكوّن.
