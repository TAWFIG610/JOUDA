# ثقة يوني | THIQA UNI

موقع شركة ثقة يوني لاستشارات القبول الجامعي في ماليزيا، بالعربية والإنجليزية. يعرّف بالشركة وخدماتها والجامعات، ويتضمن أداة لاختيار التخصص ونموذج استشارة يُرسل عبر واتساب.

## التقنيات

- React 19 و TypeScript
- Vite
- Tailwind CSS v4
- Lucide React للأيقونات
- Oxlint لفحص جودة الكود

## البدء محلياً

يتطلب المشروع Node.js و npm.

```bash
npm install
npm run dev
```

## أوامر المشروع

```bash
npm run build   # فحص TypeScript وإنشاء نسخة الإنتاج
npm run lint    # فحص الكود باستخدام Oxlint
npm run preview # معاينة نسخة الإنتاج محلياً بعد البناء
```

## هيكل المشروع

- `src/App.tsx` ترتيب الصفحة: الواجهة ← من نحن ← كيف نعمل ← الجامعات ← التكاليف والتزاماتنا ← تجارب الطلاب ← الأسئلة الشائعة ← التواصل.
- `src/components/` أقسام الصفحة (`*Section.tsx`) ونافذة الاستشارة (`ConsultModal.tsx`).
- `src/components/ui/` النافذة المنبثقة، رأس القسم، وأيقونات واتساب والشبكات الاجتماعية الرسمية.
- `src/data/thiqaData.ts` كل محتوى الموقع.
- `src/i18n/` تبديل اللغة واتجاه الصفحة.
- `src/lib/` التتبع (`analytics.ts`) وحفظ الطلبات (`leads.ts`).
- `src/index.css` نظام التصميم: خط Alexandria، الألوان، 6 مقاسات للنص، الأزرار والبطاقات.
- `design/redesign/` نموذج التصميم المرجعي ومقارنة الخطوط (ليس جزءاً من الموقع).

## المحتوى المطلوب إضافته

كل حقل فارغ في `src/data/thiqaData.ts` يبقى مخفياً، ويظهر تلقائياً عند تعبئته بمعلومة حقيقية:

- `COMPANY` الاسم المسجّل، رقم SSM، العنوان ورابط الخريطة، ساعات العمل، البريد، سنة التأسيس، عدد الطلاب، عدد المستشارين، مدة الرد، تفويض الجامعات.
- `TEAM` أسماء المستشارين وصورهم ومناصبهم.
- `HERO_IMAGE` و `PHOTOS.arrival` صور حقيقية (توضع في `public/photos/`).
- `PARTNER_UNIVERSITIES` مواعيد القبول والرسوم وشروط القبول لكل جامعة.
- `COSTS` و `COSTS_UPDATED` أرقام التكاليف وتاريخ التحديث (يظهر الجدول عند تعبئة رقمين على الأقل).
- `FAQS` إجابات أسئلة الرسوم، مواعيد القبول، المنح، الاسترداد، وتكلفة المعيشة.
- `TESTIMONIALS[].photo` و `GOOGLE_REVIEWS_URL` صور الطلاب (بموافقتهم) ورابط تقييمات Google.

## الإعدادات الاختيارية

انسخ `.env.example` إلى `.env.local` (أو أضف القيم في لوحة الاستضافة). كل إعداد يبقى معطّلاً إذا تُرك فارغاً:

- `VITE_GA_ID` — معرّف Google Analytics 4 لتتبع الزيارات والضغطات (فتح النموذج، الإرسال، واتساب، تغيير اللغة).
- `VITE_PLAUSIBLE_DOMAIN` — بديل Plausible لنفس التتبع.
- `VITE_LEADS_ENDPOINT` — حفظ نسخة من كل طلب في Google Sheets. خطوات الإعداد في `docs/google-sheet-leads.md`.

## اللغات

الموقع بالعربية افتراضياً، والنسخة الإنجليزية عبر زر اللغة أو الرابط `?lang=en`. النصوص في `src/data/thiqaData.ts` وفي كائن `TEXT` داخل كل مكوّن.
