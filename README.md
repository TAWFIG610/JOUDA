# ثقة يوني | THIQA UNI

موقع تعريفي عربي لخدمات التوجيه الأكاديمي والقبول في الجامعات الماليزية. يقدّم الموقع معلومات عن الجامعات والخدمات، وأداة لتحديد المسار الدراسي، ونموذجاً لمشاركة تفاصيل الاستفسار عبر واتساب.

## التقنيات

- React 19 و TypeScript
- Vite
- Tailwind CSS v4
- Lucide React للأيقونات
- Oxlint لفحص جودة الكود

## البدء محلياً

يتطلب المشروع Node.js و npm.

```bash
npm install
npm run dev
```

## أوامر المشروع

```bash
npm run build   # فحص TypeScript وإنشاء نسخة الإنتاج
npm run lint    # فحص الكود باستخدام Oxlint
npm run preview # معاينة نسخة الإنتاج محلياً بعد البناء
```

## هيكل المشروع

- `src/components/` مكونات الواجهة.
- `src/data/thiqaData.ts` محتوى الموقع وبيانات الجامعات.
- `src/types/` تعريفات TypeScript المشتركة.
- `public/` الشعار وأصول الجامعات والملفات العامة.
