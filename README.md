# جَــوْدَة — JOUDA | البوابة المتميزة للدراسة في ماليزيا

منصة وصفحة هبوط رسمية فائقة الفخامة والأناقة لشركة **جودة (JOUDA)** للاستشارات والخدمات الطلابية، المخصصة لمساعدة الطلاب الدوليين على بدء رحلتهم التعليمية في ماليزيا.

---

## ✨ المميزات الرئيسية (Key Highlights)

- **واجهة عربية أصيلة (Arabic-First & Native RTL)**: تصميم مبني من الصفر ليدعم الاتجاه من اليمين لليسار (`dir="rtl"`) مع خط `IBM Plex Sans Arabic`.
- **تجربة تفاعلية غنية (Signature Student Journey)**: خريطة مسار الطالب التفاعلية المكونة من 8 محطات رئيسية من بلد الطالب حتى الحرم الجامعي.
- **مستشار التخصص والجامعة الذكي (Pathway Advisor Modal)**: أداة تفاعلية سريعة من 3 خطوات لاقتراح المسارات المناسبة للطالب بناءً على مستواه وتخصصه وميزانيته.
- **دليل الجامعات الماليزية (Universities Explorer)**: تصفية وبحث فوري للجامعات الحكومية والخاصة مع تفاصيل الرسوم والترتيب العالمي وفصول القبول.
- **دليل التخصصات المستقبلية (Future Programs)**: استعراض شامل لتخصصات الذكاء الاصطناعي، الأمن السيبراني، الهندسة، إدارة الأعمال، علوم البيانات، والعلوم الصحية.
- **نموذج التقاط المهتمين عالي التحويل (Lead Capture Modal)**: نموذج جمع بيانات متوافق مع كافة المعايير مع إطلاق احتفال Confetti ومتابعة فورية عبر واتساب.
- **زر واتساب العائم (WhatsApp Floating Button)**: مثبت بالزاوية المناسبة للغة العربية (Bottom-Start) مع نبض هادئ وتلميح توضيحي.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4 + Custom Mesh Gradients & Glassmorphism
- **Icons**: Lucide React
- **Animations & Effects**: Framer Motion + Canvas Confetti
- **Linting & Quality**: Oxlint + TypeScript strict mode

---

## 🚀 تشغيل المشروع محلياً (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build

# فحص الكود والجودة
npm run lint
```
