# ثقة يوني | شريكك الأكاديمي الدولي للتعليم العالي — THIQA UNI

منصة وبوابة رقمية رسمية لـ **ثقة يوني (THIQA UNI)** للاستشارات والخدمات الأكاديمية الدولية، المخصصة لتوجيه وقبول الطلاب الدوليين في أفضل الجامعات المعترف بها في ماليزيا وآسيا.

---

## 🌟 المميزات الرئيسية (Key Highlights)

- **الهوية البصرية الرسمية (THIQA UNI Brand)**: متطابقة بالكامل مع شعار ثقة يوني الرسمي، ونظام ألوان أكاديمي دولي (Navy `#0F254B` و Gold `#F59E0B`).
- **مسار الطالب في 4 مراحل (استكشف ← قارن ← اختر ← قدّم)**: مسار أكاديمي منظم يضمن للطلاب رحلة واضحة من الاستكشاف والمقارنة وحتى استلام القبول والتأشيرة (VAL).
- **شريط الجامعات الشريكة اللانهائي (Partner Universities Marquee)**: استعراض انسيابي سلس ومعتمد لأبرز الجامعات الحكومية والخاصة والدولية في ماليزيا.
- **مستشار التوجيه الأكاديمي (Pathway Advisor Modal)**: أداة تفاعلية سريعة لاقتراح المسارات المناسبة للطالب بناءً على مستواه الأكاديمي، تخصصه المطلوب، وميزانيته السنوية.
- **نموذج التقاط المهتمين المطور (Lead Capture Modal)**: لوحة تقديم وقبول جامعي عالية التحويل مع اختيار الرمز السريع للدول والمراحل الدراسية والتخصصات، وتكامل فوري مع واتساب.
- **زر واتساب العائم (WhatsApp Floating Button)**: للتواصل المباشر مع المستشار الأكاديمي المعتمد.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Animations & Effects**: Canvas Confetti
- **Linting & Quality**: Oxlint + TypeScript strict mode

---

## 🚀 تشغيل المشروع محلياً (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build

# فحص الكود والجودة
npm run lint
```
